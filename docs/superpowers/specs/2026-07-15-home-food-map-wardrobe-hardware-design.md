# Home Food Map 衣柜把手调整设计

## 目标

仅调整 `home-food-map` 衣柜模型的五金：双开门的两枚猫爪拉手，以及两个下部抽屉圆钮。柜体、比例、猫耳顶冠和植物木雕保持不变。

## 视觉设计

- 每扇柜门使用一枚朝正面凸起的猫爪拉手。
- 拉手最外层为猫爪轮廓形的棕色描边；描边清楚分隔猫爪与门板。
- 轮廓内部为米色填充面，形成浅色的雕刻底。
- 中央肉垫与四个脚趾为深色，并高于米色填充面，形成最明显的层级与投影。
- 两个下部抽屉使用与整体协调的暖金色、圆润凸起的圆钮；不引入新图案。
- 金属/木雕混合质感采用暖蜂蜜金调，适度金属度和较低粗糙度，使高光、侧影和凸起在正面及 45° 视角可见。

## 模型实现

1. 更新 Blender 衣柜构建脚本中的猫爪拉手层级：棕色轮廓、米色底面、深色肉垫及四个独立趾垫。
2. 为两个抽屉加入相同暖金系的半球圆钮，位置位于各抽屉中心并向前凸起。
3. 重新导出 `cabinet.glb`，前端继续加载此模型而非改变布局或交互逻辑。
4. 扩展针对拉手、抽屉圆钮、配色和凸起层级的自动化检查；先使检查失败，再实施模型修改。

## 验收标准

- 正面能清楚看到两个猫爪：棕色猫爪形外框、米色内部、深色肉垫与四个脚趾。
- 深色肉垫和脚趾相对米色底面具有可见凸起和阴影。
- 两个抽屉都有暖金色凸起圆钮。
- 衣柜原有柜体与装饰不受影响，导出的 GLB 不包含贴图节点。
- 输出正面与右前 45° 预览图以供人工确认。
