# Inn floor collection

Approved 256 × 256 floor sprites for the inn-building demo. All visible tile bounds are aligned to the same 220 × 220 canvas area so they can be swapped without changing placement scale.

| File | In-game name |
| --- | --- |
| `blue-inlay.png` | 蓝纹木地板 |
| `oak-leaf.png` | 橡叶拼花地板 |
| `flower-window.png` | 花窗地板 |
| `blue-star.png` | 蓝星花砖 |
| `blue-scallop.png` | 海湾花砖 |
| `walnut-herringbone.png` | 胡桃拼花地板 |
