# 民宿模拟经营游戏：首版设计

**日期：** 2026-07-15  
**状态：** 已完成设计讨论，等待用户审阅  
**目标平台：** 手机竖屏  
**美术方向：** 温暖复古像素风

## 1. 产品定位

一款面向手机竖屏的深度模拟经营游戏。玩家长期经营和改造不同地区的民宿，通过有限空间内的设施布局、客群匹配、服务分工和地区规则，获得收入、口碑与独特性。

游戏借鉴轻量像素经营游戏的可读性和数值乐趣，但使用原创世界观、地区、角色、美术、UI、文案与内容。它不复刻任何现有游戏的资产、关卡、数值表或具体表现。

单次游玩应支持 10–15 分钟以上的连续规划与决策；竖屏只降低操作负担，不降低经营深度。

## 2. 核心体验目标

1. 玩家能从设施邻接、分区与空间扩张中获得“改一点就变好”的布局乐趣。
2. 图册提供可发现、可验证的经营知识，而非单纯的收藏清单。
3. 客群偏好使收入、满意度、安静度和空间效率之间存在真实取舍。
4. 每个地区通过独立的环境规则改变最佳解，避免后期只靠累计数值碾压。

## 3. 首版地区：澜申里洋房

澜申里洋房是一处受都市老洋房气质启发的原创地区。玩家接手一栋空间有限、隔音普通的三层旧洋房，将其改造成具有鲜明定位的民宿。

### 地区规则

- 邻里安静度限制夜间热闹设施，违规会触发投诉并影响口碑。
- 老建筑部分房间和区域处于封存状态，不能直接使用。
- 修缮和扩展能开启阁楼、旧阳台、储物间和后院等特殊区域。
- 首发客源以商务客和文艺游客为主，后续逐步加入亲子家庭和周末情侣。

### 通关与评级

一个经营周期为 7 个游戏日。周期末结算收入、口碑、图鉴进度、员工状态和地区声望。达成持续目标后，按民宿定位授予不同地区称号，例如“商务精品旅宿”“城市文化据点”或“周末约会名所”。

## 4. 单日经营循环

每个游戏日包含三段：

1. **入住准备：** 调整房价、设施、服务配置和员工分工；必要时改造布局。
2. **营业观察：** 客人入住并产生需求、满意或问题；玩家查看原因并决定是否干预。
3. **日结复盘：** 结算收入、评价、员工疲劳和图鉴线索，预告下一日客流和事件。

周期内会出现设计展周、连日降雨、邻里投诉等事件，改变客群需求或环境条件，要求玩家重新平衡布局。

## 5. 满意度、客群与评分

民宿的通用满意度由六项指标组成：

| 指标 | 主要作用 |
| --- | --- |
| 舒适度 | 提升整体好评与可接受房价 |
| 安静度 | 影响商务客、情侣和长住客体验 |
| 氛围感 | 影响文艺客、情侣和传播热度 |
| 便利度 | 影响入住效率与通用满意度 |
| 服务感 | 影响复购率与负面事件恢复 |
| 独特性 | 吸引高端客并提高图册评价 |

澜申里洋房另有地区专属的**邻里安静度**。热闹设施、夜间活动和不当动线会降低该值；过低时会限制营业并产生投诉。

每名住客按自己的偏好，对以上指标加权评分。评分进一步影响消费额、评价、复住可能和口碑传播。

首版包含四类客群：

| 客群 | 偏好 | 主要取舍 |
| --- | --- | --- |
| 商务客 | 安静、网络、快速入住 | 收入稳定，但对噪音敏感 |
| 文艺游客 | 装饰、书吧、展陈 | 消费较高，要求风格协调 |
| 亲子家庭 | 大房、安全、儿童设施 | 停留较长，空间和清洁成本较高 |
| 周末情侣 | 景观、私密、餐饮 | 房价较高，对氛围特别敏感 |

## 6. 图册系统

图册是策略百科、收藏系统和新内容引导的结合，包含五个页签：

| 页签 | 内容 | 经营价值 |
| --- | --- | --- |
| 设施组合 | 设施的空间配方和邻接关系 | 指导布局，显示有效范围与指标加成 |
| 风格套装 | 复古、自然、现代等成套搭配 | 提升独特性，解锁主题客群和房价空间 |
| 客群档案 | 偏好、厌恶项、消费习惯 | 帮助按目标客群做改造 |
| 服务手册 | 早餐、接送、清洁、管家、活动 | 提供服务策略和事件应对方式 |
| 地区纪念册 | 地标、特产、挑战规则 | 记录地区目标并解锁专属组合 |

条目的解锁来源包括：首次发现组合、完成住客委托、达成高分结算、消耗灵感研究、达成完美组合、特殊天气/节庆/稀有客触发，以及从差评复盘获得线索。

每个条目依次提供：

1. 发现条件或谜面提示；
2. 明确的布局提示图与触发范围；
3. 对六项满意度、客群评分和地区规则的具体影响。

示例：

- **窗边阅读角：** 书架、单人椅与落地灯；提高氛围感和安静度。
- **都会办公套房：** 书桌、高速网络与隔音墙；显著提高商务客满意度。
- **复古下午茶区：** 茶桌、花艺与唱片机；提高氛围感和独特性，但降低相邻区域安静度。
- **亲子安心房：** 家庭床、防护设施与收纳柜；提高舒适度和服务感。

## 7. 设施与空间扩张

首版提供约 20–25 件基础设施和 8–12 个可发现组合。设施具有标签（如安静、景观、社交、舒适、亲子、复古）、占格、有效范围、邻接效果和可能的负面效果。

玩家以有限的格位做空间取舍。首版洋房包含约 20–30 个初始可布置格位，并具有 4–6 个后续可解锁区域。

### 周游改造商

每个经营周期结束时，周游改造商有机会造访，提供限量商品：

- **扩展锤：** 开启一块封存区域，永久增加可布置空间。
- **特殊设施线索：** 提示或解锁稀有图册条目。
- **临时服务道具：** 用于特定周期内应对事件或补强服务。

扩展区域拥有独特特性：

- 临街阳台：景观加成高，但噪音也高。
- 阁楼：适合安静客房，便利度略低。
- 后院：适合茶区、花艺与社交型组合。

扩展锤以游戏内资金购买，并受地区声望或图鉴完成度限制。首版不将空间扩展设计为付费墙。

## 8. 员工、教程管家与事件

首版有 2 名员工，玩家可将其分配到前台、客房或餐饮岗位；在岗会提升服务感并每日累积疲劳，休息可恢复疲劳。员工细节不在首版扩展为复杂的人际系统。

另有 1 名教程管家，不参与经营数值、岗位分配或疲劳计算。管家只在首次游玩时引导玩家依次完成“查看洋房、购买设施、放置设施、发现组合、开始营业、日结”六个操作；每一步高亮目标 UI 并阻止跳过当前步骤的关键操作。完成后保存 `tutorial_completed` 状态，管家改为可手动打开的帮助入口。

首版事件为 2–3 种高可读的地区事件：

- 设计展周：文艺游客增加，展陈与公共空间需求提高。
- 连日降雨：客人更依赖室内公共空间，景观价值下降。
- 邻里投诉：限制夜间噪音设施，并要求短期改善安静度。

## 9. 多地区成长结构

首版只完整实现澜申里洋房；其他地区先作为后续内容定义和地图预览，规则以独立配置接入通用经营系统。

| 原创地区 | 气质参考 | 新规则与策略 |
| --- | --- | --- |
| 晴湾海镇 | 热带海滨度假地 | 淡旺季、暴雨台风、海景价值 |
| 雾港小岛 | 山海离岛聚落 | 渡轮补给、坡地动线、周末短住客 |
| 云岚温泉乡 | 高原与温泉乡 | 四季天气、温泉品质、疗愈与私密性 |
| 溪桥古镇 | 江南水乡古镇 | 文保限制、节庆客流、街坊关系 |
| 天山营地 | 辽阔山野营地 | 昼夜温差、户外安全、补给与景观资源 |

完成地区后，玩家保留通用设施和图册知识；新地区凭借独立客群权重、专属设施和环境规则提供新的解法。

## 10. 系统边界与数据流

系统按可配置、可扩展的边界拆分：

1. **地区配置：** 地图格位、地区规则、环境事件和可用内容。
2. **设施定义：** 标签、占格、范围、加成、冲突与价格。
3. **组合规则：** 触发条件、区域范围、图册解锁与效果。
4. **住客模型：** 客群偏好、预算、评分权重和评价规则。
5. **结算服务：** 汇总日结/周期结算、资金、口碑、声望和图册进度。
6. **UI 状态：** 布局编辑、营业观察、图册、商人与结算界面，以及首次教程管家的步骤状态。

数据流为：地区与玩家布局、员工分工 → 设施/组合效果计算与服务感修正 → 住客满意度评分 → 事件修正 → 收入、评价和图册结算 → 保存进度、教程完成状态与下一日预告。

无效摆放、冲突组合、资金不足或不可达区域都应在操作当下给出明确原因，且不得破坏已保存布局。结算应使用可复现的规则和测试种子，以便定位评分异常。

## 11. 首版验收与测试重点

首版以以下标准验收：

1. 玩家能在单个 7 日周期内完成设施摆放、营业、日结和周期结算。
2. 至少 8 个设施组合可按图册提示发现、显示加成并影响客群评分。
3. 四类客群在同一布局下能产生可观察的不同满意度结果。
4. 邻里安静度、一个扩展区域和周游改造商能形成可验证的长期取舍。
5. 两名员工的分工与疲劳、首次教程管家的步骤推进和完成状态、存档、日结、组合计算、客群评分和区域扩展均具有自动化测试；UI 包含对无效操作的说明。

## 12. 刻意不纳入首版的内容

- 多地区的完整地图和内容制作。
- 复杂的员工剧情、恋爱或社交关系。
- 联机、排行榜、玩家交易。
- 大量随机生成和无限房屋编辑。
- 付费道具、抽卡或以空间扩展为核心的付费限制。
